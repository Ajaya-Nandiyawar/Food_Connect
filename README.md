

# Food Connect

Food Connect is a web platform designed to bridge the gap between NGOs, restaurants, and households by encouraging the donation of surplus food. This initiative not only reduces food waste but also ensures that surplus food reaches those in need efficiently and safely.

---

## Features

1. **User-Friendly Interface:**

   - Intuitive and easy-to-navigate design for seamless user interaction.

2. **Three User Roles:**

   - **NGOs:** Register and track food donations, receive surplus food from donors, and manage logistics.
   - **Restaurants:** Donate surplus food, schedule pickups, and track past donations.

3. **Real-Time Tracking:**

   - Track food donations from donors to recipients.

4. **Advanced Search Options:**

   - Search for nearby NGOs or donors based on location.

5. **Secure Communication:**

   - Built-in chat system to coordinate pickups and clarify donation details.

6. **Analytics Dashboard:**

   - Donors and NGOs can monitor their impact, including the amount of food donated and beneficiaries served.

7. **Social Media Integration:**

   - Share donation milestones to encourage others to contribute.

---

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript.
- **Backend:** Node.js.
- **Database:** MySQL for efficient data storage.
- **Geolocation Services:** Google Maps API for location tracking.
- **Hosting:** Deployed on platforms like Netlify or Vercel.

## How to Get Started

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/yourusername/food-connect.git
   ```

2. **Install Dependencies:**

   ```bash
   cd food-connect
   npm install
   ```

3. **Set Up Environment Variables:**

   - Create a `.env` file in the root directory.
   - Add the necessary API keys and database credentials.

   Example:

   ```
   DB_HOST=your_database_host
   DB_USER=your_database_user
   DB_PASSWORD=your_database_password
   GOOGLE_MAPS_API_KEY=your_google_maps_api_key
   ```

4. **Run the Application:**

   ```bash
   npm start
   ```

5. **Access the Platform:**

   - Open your browser and navigate to `http://localhost:3000`.
